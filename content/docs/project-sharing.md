# Sharing a project

You can give colleagues access to a whole project: its files, its analyses and all its results.

## Inviting someone

1. Open the project. In the menu at the top of the project overview, choose **Members**.
2. Under **Invite Member**, type their **Email Address**.
3. Choose a **Role** (see below).
4. Click **Send Invitation**.

**The person needs a GenoLens account.**

- If they already have one, they get access straight away and receive an email with a link to the project. The project then appears in their **Projects** list.
- If they do not, GenoLens emails them an invitation to sign up, but **does not add them to the project**. Once they have created their account, invite them again.

## Roles

| | **User** (View & Analyze) | **Admin** (Full Access) | **Owner** |
|---|---|---|---|
| See datasets, analyses and all results | ✓ | ✓ | ✓ |
| Explore, filter, export results | ✓ | ✓ | ✓ |
| Upload, replace or delete datasets; import from GEO | | ✓ | ✓ |
| Launch analyses | | ✓ | ✓ |
| Edit or delete the project | | ✓ | ✓ |
| Manage members | | | ✓ |

The **owner** is the person who created the project. Analyses launched by a member count against the quota of the person who launches them.

Some modules depend on the viewer's own account, not on the project. A member without the Pro plan will not see the AI interpretation, and a member without an add-on will see its modules locked, even on a project shared by someone who has them.

## Changing a role or removing a member

In **Members**, under **Current Members**:

- **Edit Role** switches a member between User and Admin. Click **Save** to confirm.
- **Remove** takes away their access to the project. Nothing they created is deleted.

## Good practice

- Give **User** by default, and **Admin** only to people who will upload data or launch analyses.
- To share a precise view, such as a comparison at given thresholds with a set of selected genes, copy the page address: members who open it see the same view.
- To share results with someone outside GenoLens, send an export or a PDF report instead (see [Exports and PDF reports](/docs/exports-and-reports)).
